# Miu TOEIC visual direction

The learning app resembles a tidy pastel study notebook. The cream paper base holds dark plum text. Pink, lavender, mint and butter yellow are used as stickers for meaningful state and category distinctions. One illustrated kitten mascot is the recognizable signature; study surfaces remain visually quiet.

Typography: Nunito for prominent headings; Be Vietnam Pro for body and learning text. Rounded edges are used on cards and controls, with soft offset shadows only where surfaces lift. The mobile experience prioritizes one main action per view and a four-item bottom navigation.
